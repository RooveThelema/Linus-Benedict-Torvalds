Список терминов / Glossary of Terms

Дата статьи: 17 сентября 2028 года

Ядро (Kernel)
Главная часть операционной системы. Торвальдс написал ядро Linux с нуля в 1991 году.
The core of an operating system. Torvalds wrote the Linux kernel from scratch in 1991.
Git
Распределенная система контроля версий для отслеживания изменений в исходном коде.
A distributed version control system designed to track changes in source code.
Commit
Фиксация изменений в истории проекта.
A snapshot of changes saved into the project's repository history.
Дистрибутив Linux (Linux Distribution)
Операционная система, включающая в себя ядро Linux, системные библиотеки и набор утилит.
An operating system built on the Linux kernel, system libraries, and various utility software packages.
